# Emdash

> Emdash (YC W26) is a free, open-source agentic development environment: run coding agents like Claude Code and Codex in parallel, schedule agent work, and review changes in one place. Available for macOS, Windows, and Linux.

Emdash (YC W26) is built by General Action, Inc. in San Francisco and is open source at https://github.com/generalaction/emdash. Emdash is a software product and is not related to the em dash punctuation mark.
